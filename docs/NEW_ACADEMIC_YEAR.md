# Starting a new academic year (admin guide)

Admin → **New Academic Year**.

1. Type the new year's name (e.g. `2027`). It is suggested for you.
2. Open any class to see its students. **Tick anyone who must repeat** – they stay in their current class.
3. Leave "Replace all class join codes" ticked (last year's codes stop working, new Level-3 students use the fresh ones).
4. Press **Start new academic year** and confirm.

**What happens**

| Who | Result |
|---|---|
| Student in L3-SOD, not ticked | moves to L4-SOD (same stream, next level) |
| Student ticked "repeat" | stays in the same class |
| Student in a class with no next level (e.g. L5) | becomes **Graduated**: read-only sign-in for 12 months (see results, cannot submit), then blocked |
| Last year's assignments, quizzes, grades, announcements | kept, filed under last year; shown in reports (choose the year) and in each student's results |
| New year | starts with no assignments or announcements. Learning **materials** carry over to the new class intake |
| Join codes | replaced |

**Undo.** The latest promotion can be undone from the same page, until a teacher adds work or an announcement to the new year. Students you moved by hand afterwards are left where they are.

**Other tools**: Students → *Move class* (a student changes stream), *Deactivate/Restore* (keeps grades), *Erase* (deletes everything, cannot be undone), *Graduated* tab (alumni).

Add a new level or stream with **Classes → Add class**. Promotion follows `level + 1`, same stream.
